# Educational workflows — STUB

> Status: **in design.** This folder is a scaffold; no workflow is written up yet.

**Customers:** teachers, course owners, curriculum leaders — and the staff who
deliver teaching (upskilling).

**Premise:** bring modern pharmaceutical data science into pharma education, with
good didactics (the Pedagogic Practices reference model carries real weight here).

## Planned workflows

| Workflow | Customer trigger | Notes |
|---|---|---|
| **Course Upgrade** | "My course doesn't have enough modern PDS." | Add PDS + AI to an existing course; produces an upgrade plan. |
| **Staff Upskilling** | "Our staff needs new skills." | Build new PDS skills in teaching staff; clarity on what/how to learn. |
| **New Course Creation** | "We need a new course with lots of PDS." | Often CPDSE-initiated; design a PDS-rich course from scratch. |

## How the reference models apply
- **Pharma Value Chain Model** — anchor course content to the pipeline stage(s) it
  should cover.
- **PDS Competence Model** — define which competencies the course/staff should
  reach, and at what level (L1–L5).
- **Pedagogic Practices** — design the course/teaching with the 4Cs + Six Trumps.
