# Internal self-improvement — STUB

> Status: **stub / deferred.** Not customer-facing. Defined later.

How CPDSE improves *itself* — distinct from the Research and Educational workflows
that serve external customers.

**Scope (provisional):**
- **Onboarding** — bringing new CPDSE consultants/collaborators up to speed.
- **Infrastructure building** — the shared tooling, reference models, and
  workflows that make the customer-facing services work. *This project
  (`cpdse-service-workflows`) is itself an example of internal self-improvement.*

This connects to the **"value for us"** return that every customer engagement
produces — the learning loop where `[BEYOND REFERENCE]` / `[OUTSIDE MODEL]` flags
feed back into the reference models. Formalising that loop into an explicit
internal workflow is future work.

Note: staff **upskilling** is *not* here — that serves teaching staff and lives
under [Educational](../educational/).
