# PDS Competence Model – Canonical Reference

This document defines the **authoritative list of Pharmaceutical Data Science (PDS)
competences**, organised by category, subcategory, and level.

The competence model is **course-agnostic**. Courses reference competences by ID,
but competences do not reference courses.
