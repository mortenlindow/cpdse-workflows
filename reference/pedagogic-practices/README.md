# Pedagogic Practices — Canonical Reference

This folder holds the **CPDSE pedagogic practices reference**: the pedagogical
basis for all CPDSE workshop and course design, drawn from Sharon L. Bowman's
*Training from the Back of the Room*.

It is one of CPDSE's reference models, and is **self-contained**: it does not
cross-reference the other models (model intersections are defined separately —
see [`../README.md`](../README.md)).

- **Canonical document:** [`Pedagogic_Practices.md`](Pedagogic_Practices.md)
- **Covers:** the **4Cs** instructional-design map (Connections, Concepts,
  Concrete Practice, Conclusions) and the **Six Trumps** brain-based principles,
  plus the 4Cs → Workshop 1 block mapping.
- **Versioning:** the `Version:` header + changelog in the canonical document is
  the model version.
